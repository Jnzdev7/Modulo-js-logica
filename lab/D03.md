# D03 - Contagem da maior sequência de dias de sol

## 1. Ideia geral
Para resolver esse problema, usamos duas variáveis:
- `atual`: conta quantos dias seguidos de sol foram encontrados até o momento.
- `maxima`: guarda o maior valor já registrado da sequência.

## 2. Lógica matemática
A ideia é transformar o problema em contagem de blocos de `1` consecutivos.

- Se o dia for `1`, a sequência continua: `atual = atual + 1`.
- Se o dia for `0`, a sequência termina: `atual = 0`.
- Sempre que `atual` ultrapassa o maior valor anterior, atualizamos `maxima`.

Em forma matemática, a lógica pode ser resumida assim:

- se `dias[i] === 1`, então `atual = atual + 1`
- se `dias[i] === 0`, então `atual = 0`
- `maxima = max(maxima, atual)`

Ou seja, estamos calculando o comprimento da maior sequência de `1`s consecutivos no vetor.

## 3. Percurso do vetor
```js
for (let i = 0; i < dias.length; i++) {
  if (dias[i] === 1) {
    atual++;
    if (atual > maxima) {
      maxima = atual;
    }
  } else {
    atual = 0;
  }
}
```

### Como funciona:
- O laço percorre o array `dias` do início ao fim.
- Se o valor atual for `1`, significa que houve um dia de sol.
- Nesse caso, o contador `atual` aumenta.
- Se a contagem atual for maior que `maxima`, o valor máximo é atualizado.
- Se o valor for `0`, a sequência de sol foi interrompida e `atual` volta a `0`.

## 4. Exibição do resultado
```js
console.log('Maior sequência: ' + maxima);
```

- A saída mostra o número correspondente à maior sequência consecutiva de dias de sol.

## Resumo
O algoritmo calcula o comprimento da maior sequência de `1`s consecutivos no vetor, reinicia a contagem quando encontra `0` e imprime o maior valor encontrado.
