# M03 - Cálculo de desconto

## 1. Leitura e conversão
- `prompt(...)` solicita ao usuário o valor da compra, armazenado em `V`.
- `Number(...)` converte o texto digitado em um número.

## 2. Estrutura condicional
```js
if (V <= 100) {
  valorFinal = V;
} else if (V <= 300) {
  valorFinal = V * 0.90;
} else {
  valorFinal = V * 0.85;
}
```

### Regras aplicadas:
- `if (V <= 100)`: até 100 reais, sem desconto.
- `else if (V <= 300)`: acima de 100 até 300 reais, desconto de 10%.
- `else`: acima de 300 reais, desconto de 15%.

## 3. Formatação da saída
```js
console.log(`Total: R$ ${valorFinal.toFixed(2)}`);
```

- `toFixed(2)` garante que o valor seja exibido com duas casas decimais.
- Exemplo: `80.00` em vez de `80`.

## Resumo
O programa aplica o desconto conforme o valor da compra e exibe o total final com duas casas decimais.
