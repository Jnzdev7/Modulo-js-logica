# Módulo 03 - Cálculo de desconto

## 1. Leitura e conversão
- `prompt(...)` solicita ao usuário o valor da compra, armazenado em `V`.
- `Number(...)` converte o texto digitado em um número.

## 2. Estrutura condicional
```js
if (V <= 100) {
  valorFinal = V;
} else if (V <= 300) {
  valorFinal = V * 0.90;
} else {
  valorFinal = V * 0.85;
}
```

### Regras aplicadas:
- `if (V <= 100)`: se a compra for de até 100 reais, não há desconto.
- `else if (V <= 300)`: se o valor for maior que 100 e até 300 reais, aplica-se 10% de desconto.
- `else`: se o valor for acima de 300 reais, aplica-se 15% de desconto.

## 3. Formatação da saída
- `valorFinal.toFixed(2)` garante que o valor seja exibido com duas casas decimais, como `80.00` em vez de `80`.
- `console.log(...)` mostra a mensagem final no terminal, no formato:

```js
console.log(`Total: R$ ${valorFinal.toFixed(2)}`);
```

Resultado esperado:
- `Total: R$ X.XX`
