# D02 - Sequência de Fibonacci até N

## 1. Inicialização das variáveis
```js
let a = 0;
let b = 1;
let termos = [];
```

- `a = 0` e `b = 1`: representam os dois primeiros valores da sequência.
- `termos = []`: armazena os termos válidos antes da impressão.

## 2. Laço de repetição (`while`)
```js
while (a <= N) {
  termos.push(a);
  const proximo = a + b;
  a = b;
  b = proximo;
}
```

### Explicação:
- `while (a <= N)`: o loop continua enquanto o valor atual de `a` for menor ou igual a `N`.
- `termos.push(a)`: adiciona o valor atual ao array.
- `const proximo = a + b`: calcula o próximo elemento da sequência.
- `a = b` e `b = proximo`: atualizam os valores para avançar na sequência.

## 3. Formatação e exibição
```js
console.log(termos.join(' '));
```

- `termos.join(' ')`: junta todos os elementos do array em uma única string, separados por espaço.
- `console.log(...)`: imprime o resultado final no formato solicitado.

## Resumo
O algoritmo gera a sequência de Fibonacci até o valor `N`, guarda os termos em um array e imprime todos em uma única linha.
