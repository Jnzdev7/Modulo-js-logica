# M01 - Verificação de ano bissexto

## 1. Leitura e conversão
- `prompt(...)` lê a entrada do utilizador.
- `Number(...)` converte o texto digitado em um valor numérico e armazena na variável `A`.

## 2. Condição lógica do ano bissexto
```js
if ((A % 4 === 0 && A % 100 !== 0) || A % 400 === 0) {
  console.log("Bissexto");
} else {
  console.log("Não bissexto");
}
```

### Regra:
Um ano é bissexto se:
- for divisível por 4 e não for divisível por 100; ou
- for divisível por 400.

### Significado dos operadores:
- `%`: resto da divisão.
- `&&`: operador lógico "E".
- `||`: operador lógico "OU".

## 3. Exibição do resultado
- Se a condição for verdadeira, o programa imprime: `Bissexto`.
- Caso contrário, imprime: `Não bissexto`.

## Resumo
A lógica verifica se o ano atende a uma das regras de bissexto e mostra o resultado final na tela.
