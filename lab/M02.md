# M02 - Cálculo de ônibus necessários

## 1. Leitura e conversão
- `require('prompt-sync')()` carrega a biblioteca para ler entradas no terminal.
- `prompt(...)` solicita os dados do usuário.
- `Number(...)` converte os valores digitados para números.

## 2. Cálculo da divisão inteira
```js
const onibus = Math.floor(P / C);
```

- `Math.floor(P / C)` calcula quantos ônibus ficam totalmente cheios.
- O `Math.floor()` arredonda para baixo, ignorando a parte decimal.

## 3. Verificação de sobra
```js
if (P % C !== 0) {
  onibus = onibus + 1;
}
```

- `P % C` calcula o resto da divisão.
- Se houver resto, significa que ainda faltam passageiros para completar um ônibus.
- Portanto, é necessário adicionar mais um ônibus.

## 4. Exibição do resultado
```js
console.log(onibus);
```

- O programa imprime o número total de ônibus necessários.

## Resumo
A lógica calcula a divisão total de pessoas por capacidade do ônibus e, se houver resto, acrescenta mais um ônibus para acomodar os passageiros restantes.
