# Módulo 04 - Verificação e classificação de triângulos

## 1. Leitura e conversão
- Lê os 3 inteiros `A`, `B` e `C` com `prompt()`.
- Converte os valores para números com `Number()`.

## 2. Verificação de existência do triângulo
```js
if (A < B + C && B < A + C && C < A + B) {
  // continua para classificação
} else {
  console.log("Não forma triângulo");
}
```

### Regra:
Para que três lados formem um triângulo, cada lado deve ser menor que a soma dos outros dois:
- `A < B + C`
- `B < A + C`
- `C < A + B`

Se qualquer uma dessas condições falhar, o programa imprime:
- `Não forma triângulo`

## 3. Classificação do triângulo
```js
if (A === B && B === C) {
  console.log("Equilátero");
} else if (A !== B && B !== C && A !== C) {
  console.log("Escaleno");
} else {
  console.log("Isósceles");
}
```

### Como funciona:
- `A === B && B === C`: todos os lados iguais → `Equilátero`
- `A !== B && B !== C && A !== C`: todos os lados diferentes → `Escaleno`
- `else`: caso não seja equilátero nem escaleno, sobra a opção com dois lados iguais → `Isósceles`

## Resumo
O programa:
1. lê os lados do triângulo;
2. verifica se eles realmente formam um triângulo;
3. classifica o triângulo em `Equilátero`, `Escaleno` ou `Isósceles`.
