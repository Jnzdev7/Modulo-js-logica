# D01 - Verificação de números primos

## 1. Variável de controle
- Criamos uma variável booleana chamada `ehPrimo`.
- Ela começa como `true`, assumindo que o número é primo até que seja provado o contrário.

## 2. Casos limite
```js
if (N <= 1) {
  ehPrimo = false;
}
```

- Se o número for menor ou igual a `1`, ele não é primo.
- Isso inclui `1` e valores negativos.

## 3. Laço de repetição
```js
for (let i = 2; i * i <= N; i++) {
  if (N % i === 0) {
    ehPrimo = false;
    break;
  }
}
```

### Explicação:
- O loop começa em `2`.
- A condição `i * i <= N` equivale a verificar até a raiz quadrada de `N`.
- Se `N % i === 0`, existe um divisor diferente de `1` e de `N`, então o número não é primo.
- `break` interrompe o laço assim que a condição é encontrada.

## 4. Exibição do resultado
```js
if (ehPrimo) {
  console.log("Primo");
} else {
  console.log("Não é primo");
}
```

- Se `ehPrimo` continuar `true`, o número é primo.
- Caso contrário, o programa imprime `Não é primo`.

## Resumo
O algoritmo verifica se o número possui algum divisor além de `1` e dele mesmo. Se encontrar um divisor, conclui que o número não é primo; caso contrário, ele é primo.
